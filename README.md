Compilation of scripts to fit the rotation profile of resolved surfaces. 

Two-step process:
1/ Using casatools, fit the emission or absorption of a line cube with a Gaussian. Output: amplitude, FWHM, and velocity image. 
2/ MCMC and least-squares fit of the velocity image with solid-body rotation. 

Additionally, a synthetic rotation profile (solid-body or differential) can be simulated for various angular resolutions.
